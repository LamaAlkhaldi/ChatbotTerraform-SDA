# 🤖 Building a Chatbot Project in Azure using Terraform

This is a simple infrastructure project that deploys a **Virtual Machine (VM)** and a **Virtual Network (VNet)** in **Microsoft Azure** using **Terraform** to host a basic chatbot application.

## 🌐 Project Overview

The purpose of this project is to automate the creation of a cloud environment for a chatbot using Infrastructure as Code (IaC). With Terraform, we provision:

- A **Virtual Network (VNet)** for isolated and secure communication
- A **Virtual Machine (VM)** to host the chatbot

The chatbot itself can be deployed manually or automatically using a startup script.
